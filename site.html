Что такое SQL: как устроен, зачем нужен и как с ним работать

Вся информация, с которой вы сталкиваетесь в интернете, содержится в базах данных. В них же хранятся данные о сотрудниках и клиентах крупных компаний, научных и социологических исследованиях, расписании рейсов ближайшего к вам аэропорта и многое другое.

Работать с этими массивами данных вручную было бы долго и неудобно. Поэтому придумали SQL — специальный язык для общения с базами данных.

Разработчики SQL

Дональд Чемберлин

Американский ученый-компьютерщик, один из главных разработчиков оригинальной спецификации языка SQL вместе с Рэймондом Бойсом. Он также внес значительный вклад в разработку XQuery. В 1997 году Чемберлин был избран членом Национальной инженерной академии за вклад в язык запросов к базам данных SQL.

Раймонд Бойс

Американский информатик, Бойс вырос в Нью-Йорке, поступил в колледж в Провиденсе. В июне 1972 года получил степень доктора философии в Университете Пердью. После ухода из Пердью работал над проектами в области баз данных для корпорации IBM в Йорктаун Хейтс. Во время работы в IBM вместе с Эдгаром Коддом разработал нормальную форму Бойса — Кодда. Будучи главой группы разработки в области реляционных баз данных, в сотрудничестве с Дональдом Чемберленом разработал язык SQL.

Основные команды SQL

SELECT

Команда SELECT используется для извлечения данных из базы данных. Это основная команда для работы с данными в таблицах. 

SELECT * FROM table_name;

INSERT

Команда INSERT используется для добавления новых записей в таблицу базы данных. 

INSERT INTO table_name (column1, column2) VALUES (value1, value2);

UPDATE

Команда UPDATE используется для изменения существующих записей в таблице базы данных. 

UPDATE table_name SET column1 = value1, column2 = value2 WHERE condition;

DELETE

Команда DELETE используется для удаления записей из таблицы базы данных. 

DELETE FROM table_name WHERE condition;

WHERE

Команда WHERE используется для указания условий фильтрации данных. Она часто применяется вместе с другими командами, такими как SELECT, UPDATE и DELETE. 

SELECT column1, column2 FROM table_name WHERE condition;

JOIN

Команда JOIN используется для объединения данных из нескольких таблиц на основе связанных столбцов. 

SELECT column1, column2 FROM table1 JOIN table2 ON table1.column = table2.column;

GROUP BY

Команда GROUP BY используется для группировки записей, которые имеют одинаковые значения в одном или нескольких столбцах. 

SELECT column, COUNT(*) FROM table_name GROUP BY column;

ORDER BY

Команда ORDER BY используется для сортировки результатов выборки по одному или нескольким столбцам. 

SELECT column1, column2 FROM table_name ORDER BY column1 ASC;

LIMIT

Команда LIMIT ограничивает количество строк, которые возвращаются в результате запроса. 

SELECT column1, column2 FROM table_name LIMIT 10;

Как выбрать столбцы name и age из таблицы students?

SELECT name, age FROM students;

Информация о студентах записана в таблицу students. Как выбрать только тех студентов, чей возраст больше 18?

SELECT * FROM students
WHERE age > 18;
